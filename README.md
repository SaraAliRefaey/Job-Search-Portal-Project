# 💼 Job Search Portal System

## 📌 Project Overview
The **Job Search Portal** is a web-based application designed to bridge the gap between job seekers and recruiters. It provides a platform for candidates to search, filter, and apply for open positions, while empowering recruiters to manage job postings, review applications, and track candidates via an interactive dashboard.

---

## 🛠️ Tech Stack & Technologies
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS / Dynamic Routing)
- **Backend & Logic:** Python
- **Styling & Assets:** Custom CSS, Webfonts, Responsive Web Design

---

## 🚀 Key Features

### 👤 For Job Seekers
- **Account Management:** User registration (`SignUp.html`) and secure login (`Login.html`).
- **Job Discovery & Search:** Browse and search available listings on the main portal (`index.html`, `AppJob.html`).
- **Application Process:** Easy interface to apply for open vacancies directly.

### 👔 For Recruiters & Admin
- **Recruiter Dashboard:** Centralized dashboard (`Recruiter Dashboard.html`) to oversee listings and application statuses.
- **Job Management:** Capabilities to create (`add_job.html`) and edit/update (`edit_job.html`) active job postings.
